# UNC603: Programming Practices Lab - I
**Semester**: Semester VI | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 0-0-4 | **Credits**: 2.0 | **Contact Hours**: 4

## 🎯 Course Objective
To provide intensive programming practice strengthening problem-solving ability through regular coding exercises based on data structures and algorithmic techniques for technical interviews.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Apply programming skills in Java/Python to solve computational problems.
- **CLO2**: Implement solutions using appropriate data structures and algorithmic techniques.
- **CLO3**: Develop logical reasoning and structured problem-solving ability through coding practice.
- **CLO4**: Perform timed programming tasks with attention to correctness and efficiency.

## 📚 Syllabus & Topics
- Programming in Java: OOP concepts, collections, multithreading, stream API.
- Programming in Python: Core constructs, scripting, rapid prototyping.
- Structured Problem Solving: Competitive programming problems, complexity optimization, interview-style scenario testing.
- Standards Familiarization: IEEE 1061-1998, IEEE 1012-2016, IEEE 730-2014, POSIX IEEE 1003.1.

## 📖 Prescribed Text Books & References
1. Halim, Steven and Halim, Felix, Competitive Programming, CP Handbook.
1. McDowell, Gayle Laakmann, Cracking the Coding Interview, CareerCup.
