# UEC615: Embedded Systems and IoT
**Semester**: Semester VI | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To equip students with necessary knowledge of C++ firmware development, ARM processor architecture and interfacing, and protocols required to build real-life IoT projects.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Understand embedded system models using C++ language.
- **CLO2**: Understand internal architecture of ARM processor, register structure, and addressing modes.
- **CLO3**: Design ARM interfacing with memory, I/O devices, and peripherals using C++.
- **CLO4**: Analyze design aspects of hardware and software components of IoT including protocols.
- **CLO5**: Design interfaces for I/O devices, sensors, and communication modules.

## 📚 Syllabus & Topics
- Embedded Systems Architecture: General vs Embedded systems, Object-oriented firmware in C++, GPIO drivers, register access.
- ARM Processor: Architecture, register set, CPSR, ARM vs Thumb state, instruction set, interrupts, exceptions.
- Peripherals & Protocols: AMBA bus, DMA, UART, I2C, SPI interfacing, memory management unit.
- Internet of Things (IoT): Architectural overview, sensing, actuation, M2M, MQTT, ZigBee, CoAP, HTTP, cloud platforms for IoT, edge computing.
- Standards Familiarization: IEEE P2413-2019, IEEE 1451, IEEE 802.15.4, IEEE P1838.
