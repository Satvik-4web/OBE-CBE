# UEC716: Database Management Systems
**Semester**: Semester IV | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To provide students with a strong foundation in the principles, design, and implementation of database systems, while understanding concepts of database architecture, normalization, transactions, and query optimization.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Analyze Information Systems as socio-technical systems, its need and advantages as compared to traditional file-based systems.
- **CLO2**: Analyze and design database using E-R data model by identifying entities, attributes and relationships.
- **CLO3**: Apply and create Relational Database Design process with Normalization techniques.
- **CLO4**: Comprehend concepts of transaction management, concurrency control and recovery management.
- **CLO5**: Demonstrate use of SQL and PL/SQL to implement database applications.

## 📚 Syllabus & Topics
- Introduction & Architecture: Data Abstraction, Data Independence, Data Definition and Data Manipulation Languages.
- Data Models & Relational Algebra: Entity-relationship model, relational model, integrity constraints, Relational algebra, tuple and domain calculus.
- Relational Database Design: Normalization: 1NF, 2NF, 3NF, BCNF, 4NF, 5NF, dependency preservation, lossless join decomposition.
- Database Implementation & SQL: DDL, DML, joins, subqueries, aggregate functions, PL/SQL: cursors, stored procedures, functions, triggers.
- Transaction Management & Concurrency Control: ACID properties, Serializability, Concurrency control, Lock-based protocols, Two-phase locking, Deadlocks.
- Recovery Management: Log-based recovery, checkpoints, shadow paging.
- Standards Familiarization: IEEE 610.12-1990, POSIX IEEE 1003.1.
