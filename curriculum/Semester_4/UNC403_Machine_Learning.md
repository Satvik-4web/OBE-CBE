# UNC403: Machine Learning
**Semester**: Semester IV | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To build fundamental understanding of Machine Learning (ML) and its applications, covering mathematical foundations, supervised/unsupervised paradigms, and deep neural networks.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Comprehend fundamental concepts and terminology associated with machine learning and artificial intelligence.
- **CLO2**: Apply various regression and classification techniques and evaluate models.
- **CLO3**: Implement and apply machine learning algorithms for supervised, unsupervised, and reinforcement learning tasks.
- **CLO4**: Apply and evaluate neural network models using gradient-based learning and model selection techniques.

## 📚 Syllabus & Topics
- Introduction: Supervised, Unsupervised, Reinforcement Learning, Empirical Risk Minimization, Bayes Optimality, Maximum Likelihood & MAP, k-NN.
- Regression & Classification: Linear & Logistic Regression, Regularization (Ridge, Lasso), Kernel Methods, SVM, Decision Trees, Ensemble Learning (Random Forests, Boosting), Evaluation metrics (RMSE, ROC, AUC, F1-Score).
- Learning Paradigms: Clustering (k-Means, GMM, DBSCAN), Dimensionality reduction (PCA, t-SNE), Markov Decision Processes (MDP), Q-Learning.
- Neural Networks: Perceptron, Backpropagation, CNN architectures, Transfer learning, Hyperparameter tuning.
- Standards Familiarization: IEEE 42010-2011, IEEE 1012-2016, IEEE 7000-2021, IEEE 7001-2021.
