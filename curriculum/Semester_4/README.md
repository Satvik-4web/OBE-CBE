## Course Learning Outcomes (CLOs) Quick Reference
### UEC716: Database Management Systems
- CLO1: Analyze Information Systems as socio-technical systems, its need and advantages as compared to traditional file-based systems.
- CLO2: Analyze and design database using E-R data model by identifying entities, attributes and relationships.
- CLO3: Apply and create Relational Database Design process with Normalization techniques.
- CLO4: Comprehend concepts of transaction management, concurrency control and recovery management.
- CLO5: Demonstrate use of SQL and PL/SQL to implement database applications.

### UNC311: Probability and Statistics
- CLO1: Analyze and compute statistical measures to describe and interpret data characteristics and distribution behaviour across applications.
- CLO2: Apply probability and random variable concepts to model and analyze discrete and continuous probability distributions.
- CLO3: Analyze random processes and noise models by evaluating stationarity, ergodicity, correlation functions, and power spectral density.
- CLO4: Evaluate estimation and hypothesis testing methods by assessing bias, variance, mean square error (MSE), confidence intervals, and error probabilities for engineering problems.
- CLO5: Analyze information-theoretic models and coding schemes by computing entropy, mutual information, and channel capacity, and applying source coding theorems to improve transmission efficiency and reliability.

### UNC402: Design and Analysis of Algorithms
- CLO1: Analyse the complexity of algorithms and implement it in a specific scenario.
- CLO2: Apply common algorithmic techniques such as greedy, dynamic programming etc. to standard computational problems.
- CLO3: Design solutions by using appropriate data structures or applying algorithms such as randomized, approximation and graph.
- CLO4: Develop efficient algorithms for various computational challenging problems solving in computing.

### UEC612: Digital System Design
- CLO1: Apply various minimization methods to simplify boolean functions and construct circuits using logic gates.
- CLO2: Design combinational circuits and iterative networks using basic modules.
- CLO3: Design and analyze sequential circuits and finite state machines.
- CLO4: Evaluate performance of integrated circuits across logic families.
- CLO5: Design, simulate and synthesize digital systems using HDL (VHDL/Verilog).

### UNC403: Machine Learning
- CLO1: Comprehend fundamental concepts and terminology associated with machine learning and artificial intelligence.
- CLO2: Apply various regression and classification techniques and evaluate models.
- CLO3: Implement and apply machine learning algorithms for supervised, unsupervised, and reinforcement learning tasks.
- CLO4: Apply and evaluate neural network models using gradient-based learning and model selection techniques.

### UTA024: Engineering Design Project (Buggy)
- CLO1: Recognize issues to be addressed in combined hardware and software system design.
- CLO2: Draw schematic diagrams of electronic circuits and design PCB layouts using CAD tools.
- CLO3: Apply hands-on experience in electronic circuit implementation and testing.
- CLO4: Demonstrate programming skills by integrating coding, optimization and debugging for different robotic challenges.
- CLO5: Develop group working, including task sub-division and integration of individual contributions from the team.

### UHU052: The Evolutionary Basis of Human Behavior for Engineers
- CLO1: Understand evolutionary principles influencing human behavior and cognition.
- CLO2: Analyze social dynamics, cooperation, and group decision-making in technical teams.
- CLO3: Apply behavioral insights to human-centered engineering design and workplace ethics.

### UCS421: Ethics and Risk Mitigation in AI
- CLO1: Identify ethical challenges, algorithmic biases, and societal impacts in AI deployments.
- CLO2: Apply regulatory frameworks, governance models, and data privacy principles to AI systems.
- CLO3: Formulate risk mitigation strategies, fairness audits, and accountability mechanisms for AI engineering.
