# UNC303: Computer and Communication Networks
**Semester**: Semester V | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-0 | **Credits**: 3.0 | **Contact Hours**: 3

## 🎯 Course Objective
To introduce basic concepts of Data communication with different models, layers of OSI and TCP/IP protocol suites, routing, congestion control, and network security.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Understand the layered architecture of Internet's reference models: OSI & TCP/IP and basis of physical layer and media.
- **CLO2**: Analyze design issues, framing, error detection and correction, channel allocation techniques and link layer protocols.
- **CLO3**: Evaluate network layer, internetworking, IP and IP addressing mechanisms.
- **CLO4**: Apply various routing algorithms, elements of transport protocols, congestion control, and QOS in networks.
- **CLO5**: Understand various communication applications like email, web browser, and familiarization with cryptography and network security.

## 📚 Syllabus & Topics
- Data Communication Overview: OSI model, TCP/IP protocol suite, packet switching, circuit switching.
- Data Link Layer: Framing, error detection and correction, sliding window protocols (Stop-and-Wait, Go-Back-N, Selective Repeat), HDLC, MAC protocols (CSMA/CD, CSMA/CA).
- Network Layer: IPv4 and IPv6 addressing, subnetting, CIDR, routing algorithms (Distance Vector, Link State, OSPF, BGP).
- Transport Layer: UDP, TCP connection management, flow control, congestion control algorithms, QoS.
- Application Layer & Security: DNS, HTTP, SMTP, Cryptography basics, SSL/TLS, firewalls.
- Standards Familiarization: IEEE 802.3 (Ethernet), IEEE 802.11 (Wi-Fi), IEEE 802.15.1 (Bluetooth).
