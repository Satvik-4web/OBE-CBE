# UNC514: Data Science Fundamentals (Elective-I)
**Semester**: Semester V | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PEC | **L-T-P**: 2-0-2 | **Credits**: 3.0 | **Contact Hours**: 4

## 🎯 Course Objective
To teach fundamental methods of data collection, wrangling, statistical inference, visualization, and building predictive analytics pipelines.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Understand data science pipelines and methods for acquiring structured and unstructured data.
- **CLO2**: Perform exploratory data analysis and statistical visualization.
- **CLO3**: Build and evaluate predictive regression and classification models.
- **CLO4**: Communicate data insights and deploy scalable data analysis workflows.

## 📚 Syllabus & Topics
- Data science lifecycle, data ingestion, cleaning, transformation, exploratory data analysis (EDA), statistical inference, hypothesis testing, predictive modeling using Python, data storytelling.

## 📖 Prescribed Text Books & References
1. McKinney, Wes, Python for Data Analysis, O'Reilly Media (2022).
