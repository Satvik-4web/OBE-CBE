# UEC610: Computer Architecture
**Semester**: Semester V | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-1-0 | **Credits**: 3.5 | **Contact Hours**: 4

## 🎯 Course Objective
To introduce state-of-the-art parallelism in RISC architectures, memory optimization, pipelining, multiprocessor configurations, and GPU clusters using CUDA.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Apply Amdahl's law and Processor Performance Equation to evaluate system performance.
- **CLO2**: Characterize processor instruction set architecture and addressing modes.
- **CLO3**: Identify concepts of parallelism, pipelining, and hazard removal.
- **CLO4**: Demonstrate GPU-based system acceleration using CUDA programming.
- **CLO5**: Investigate Memory Hierarchy design, memory addressing, and address translation.

## 📚 Syllabus & Topics
- Modern Computer Design: CISC vs RISC, Amdahl's Law, CPU performance equation, Benchmarking.
- Instruction Set Principles: Register-memory vs load-store, addressing modes, compiler interactions.
- Pipelining & Parallelism: Five-stage RISC pipeline, structural/data/control hazards, branch prediction, RISC-V implementation, loop unrolling.
- Multi-Core & GPUs: Multiprocessor architectures, GPU clusters, CUDA programming, cache coherence, snoopy protocols.
- Memory Hierarchy Design: Cache organization, cache miss reduction techniques, virtual memory, TLB, page tables.
- Standards Familiarization: IEEE 754 floating point arithmetic, IEEE 802, IEEE 1516.
