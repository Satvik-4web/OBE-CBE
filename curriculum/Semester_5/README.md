## Course Learning Outcomes (CLOs) Quick Reference
### UNC303: Computer and Communication Networks
- CLO1: Understand the layered architecture of Internet's reference models: OSI & TCP/IP and basis of physical layer and media.
- CLO2: Analyze design issues, framing, error detection and correction, channel allocation techniques and link layer protocols.
- CLO3: Evaluate network layer, internetworking, IP and IP addressing mechanisms.
- CLO4: Apply various routing algorithms, elements of transport protocols, congestion control, and QOS in networks.
- CLO5: Understand various communication applications like email, web browser, and familiarization with cryptography and network security.

### UEC610: Computer Architecture
- CLO1: Apply Amdahl's law and Processor Performance Equation to evaluate system performance.
- CLO2: Characterize processor instruction set architecture and addressing modes.
- CLO3: Identify concepts of parallelism, pipelining, and hazard removal.
- CLO4: Demonstrate GPU-based system acceleration using CUDA programming.
- CLO5: Investigate Memory Hierarchy design, memory addressing, and address translation.

### UEC504: Signal System and Processing
- CLO1: Analyze different properties of continuous and discrete-time signals and systems.
- CLO2: Represent signals and systems in frequency domain using Fourier tools.
- CLO3: Apply Z-transform to analyze discrete-time signals and systems.
- CLO4: Design and implement digital discrete-time filters (FIR/IIR).

### UNC514: Data Science Fundamentals (Elective-I)
- CLO1: Understand data science pipelines and methods for acquiring structured and unstructured data.
- CLO2: Perform exploratory data analysis and statistical visualization.
- CLO3: Build and evaluate predictive regression and classification models.
- CLO4: Communicate data insights and deploy scalable data analysis workflows.

### UEC523: Applications of AI for Electronic Systems
- CLO1: Understand machine learning techniques tailored for electronic sensor data.
- CLO2: Implement TinyML and embedded AI models on microcontrollers and edge hardware.
- CLO3: Optimize neural network models for power, latency, and memory-constrained electronic systems.
- CLO4: Apply AI algorithms to fault detection, circuit optimization, and signal classification.

### UEC522: Practices in Electronics Fabrication
- CLO1: Explain fundamentals of integrated circuits, semiconductor materials, crystal growth, and wafer preparation.
- CLO2: Apply principles of oxidation, diffusion, ion implantation, lithography, etching, and metallization to describe planar IC fabrication.
- CLO3: Analyse and apply various IC Design rules.
- CLO4: Understand Packaging technologies by considering electrical, thermal, and mechanical performance requirements.

### UTA025: Innovation & Entrepreneurship
- CLO1: Explain fundamentals behind entrepreneurial personality and intentions.
- CLO2: Discover, evaluate, and validate business opportunities.
- CLO3: Identify stakeholders and develop strong value propositions.
- CLO4: Describe business models and construct a functional Business Model Canvas.
- CLO5: Analyse and select suitable finance and revenue models for startup ventures.
