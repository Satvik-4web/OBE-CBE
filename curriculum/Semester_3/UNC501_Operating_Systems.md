# UNC501: Operating Systems
**Semester**: Semester III | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To understand the roles and responsibilities of an operating system in managing hardware and software resources, and to explore algorithms used for process, memory, storage, and concurrency management.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Explain the basics of an operating system viz. system programs, system calls, user mode and kernel mode.
- **CLO2**: Select a particular CPU scheduling algorithm for specific situation, and analyze the environment leading to deadlock and its rectification.
- **CLO3**: Comprehend concepts related to concurrency, synchronization, and race conditions.
- **CLO4**: Explicate memory management techniques viz. caching, paging, segmentation, virtual memory, and thrashing.
- **CLO5**: Understand concepts related to file systems, disk-scheduling, and file storage structures.

## 📚 Syllabus & Topics
- Introduction & System Structures: OS architecture, System Calls, System Programs, Operating-System Design.
- Process Management: Process Concept, Scheduling Algorithms, IPC, Multithreading, Deadlock detection, prevention and recovery.
- Concurrency: Critical Section Problem, Mutex Locks, Semaphores, Monitors, Classical synchronization problems.
- Memory Management: Swapping, Paging, Segmentation, Virtual Memory, Demand Paging, Page Replacement Algorithms (FIFO, LRU, Optimal), Thrashing.
- Disk & File Systems: Disk Scheduling (FCFS, SSTF, SCAN), RAID Structure. File access methods, directory structures, protection.
- Standards Familiarization: IEEE 1596-1992, IEEE 754-2019, IEEE 1278, IEEE 42010-2011.
