## Course Learning Outcomes (CLOs) Quick Reference
### UNC401: Data Structures
- CLO1: Implement basic data structures and solve problems using fundamental algorithms.
- CLO2: Implement various searching and sorting techniques.
- CLO3: Analyze the complexity of algorithms to provide justification for selection and implementation.
- CLO4: Apply appropriate data structure and algorithmic technique to solve real-world problems.

### UNC305: Discrete Mathematics
- CLO1: Apply Knowledge of mathematics in truth tables and the rules of propositional & predicate calculus.
- CLO2: Apply the logical and analytical structure of proofs and work symbolically with connectives and quantifiers to produce logically valid arguments.
- CLO3: Evaluate elementary mathematical arguments and identify fallacious reasoning.
- CLO4: Analyze real-world problems using graph theory.

### UNC302: Object Oriented Programming
- CLO1: Explain OOP principles, compare with procedural programming, and explore classes, objects, and methods.
- CLO2: Implement data abstraction using classes and constructors, and achieve polymorphism through function and operator overloading.
- CLO3: Apply inheritance and polymorphism concepts to enhance code reusability.
- CLO4: Analyze I/O file stream, templates and exception handling for robust programming.

### UNC501: Operating Systems
- CLO1: Explain the basics of an operating system viz. system programs, system calls, user mode and kernel mode.
- CLO2: Select a particular CPU scheduling algorithm for specific situation, and analyze the environment leading to deadlock and its rectification.
- CLO3: Comprehend concepts related to concurrency, synchronization, and race conditions.
- CLO4: Explicate memory management techniques viz. caching, paging, segmentation, virtual memory, and thrashing.
- CLO5: Understand concepts related to file systems, disk-scheduling, and file storage structures.

### UEC304: Electronics Devices and Circuits
- CLO1: Understand the working of PN junction diode and MOS transistor operation.
- CLO2: Analyze static and dynamic characteristics of Resistive load Inverter and CMOS inverter.
- CLO3: Implement various CMOS logic circuits and transmission gates.
- CLO4: Illustrate the fabrication process and design rules for NMOS and CMOS circuits.

### UCS321: AI for Engineers
- CLO1: Understand foundational artificial intelligence concepts, problem formulation, and search strategies.
- CLO2: Apply knowledge representation, logical reasoning, and probabilistic inference to engineering problems.
- CLO3: Implement supervised and unsupervised machine learning models using contemporary AI libraries.
- CLO4: Evaluate AI solutions on real-world engineering datasets considering performance and ethical dimensions.

### UTD003: Aptitude Skills Building
- CLO1: Ability to identify and provide solutions for complex problems and apply the basics of mathematics.
- CLO2: Able to analyze and interpret data from various sources to identify trends and make data-driven comparisons.
- CLO3: Able to evaluate logical reasoning scenarios to identify patterns, solve sequences, and make accurate inferences.
- CLO4: Able to improve communication skills, including correcting errors, refining structure, and enhancing verbal proficiency.
- CLO5: Able to analyze various types of information to identify key points, infer meaning, and understand underlying tones and purposes.
