# UNC401: Data Structures
**Semester**: Semester III | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To become familiar with different types of data structures and their applications and learn different types of algorithmic techniques and strategies.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Implement basic data structures and solve problems using fundamental algorithms.
- **CLO2**: Implement various searching and sorting techniques.
- **CLO3**: Analyze the complexity of algorithms to provide justification for selection and implementation.
- **CLO4**: Apply appropriate data structure and algorithmic technique to solve real-world problems.

## 📚 Syllabus & Topics
- Introduction & Complexity: Abstract data types, Data Representation, Big-Oh notation, time and space complexity, Recurrence relations, Analysis of iterative and recursive algorithms.
- Linear Data Structures: Arrays, records, linked lists, stacks, queues, priority queues, Hash tables, collision resolution strategies.
- Searching & Sorting: Linear Search, Binary Search, Bubble Sort, Selection Sort, Insertion Sort, Shell Sort, Quick Sort, Heap Sort, Merge Sort, Counting Sort and Radix Sort.
- Trees & Applications: Binary trees, Binary search trees, AVL trees, Red-black trees, B-trees, Heaps, Huffman coding.
- Graphs: Directed and undirected graphs, BFS, DFS, Shortest-path (Dijkstra, Floyd), Minimum spanning tree (Prim, Kruskal).
- Standards Familiarization: IEEE 29148-2018, POSIX IEEE 1003.1.
