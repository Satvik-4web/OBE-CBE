# UNC302: Object Oriented Programming
**Semester**: Semester III | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
To gain understanding of object-oriented programming (OOP) principles, explore their practical uses, and acquire knowledge of diverse algorithmic methods and approaches in C++.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Explain OOP principles, compare with procedural programming, and explore classes, objects, and methods.
- **CLO2**: Implement data abstraction using classes and constructors, and achieve polymorphism through function and operator overloading.
- **CLO3**: Apply inheritance and polymorphism concepts to enhance code reusability.
- **CLO4**: Analyze I/O file stream, templates and exception handling for robust programming.

## 📚 Syllabus & Topics
- Basics of OOP: Difference between OOP and procedural programming, Classes, objects and Methods, Function overloading.
- Data Abstraction & Encapsulation: Access control, Constructors, Destructor, Object lifecycle.
- Polymorphism: Function and operator overloading, Runtime polymorphism, virtual functions, abstract base classes.
- Inheritance: Derived classes, multiple inheritance, virtual base class, virtual destructors.
- I/O Streams & Templates: Stream I/O in C++, manipulators, File handling, function templates, class templates, Exception handling.
- Standards Familiarization: IEEE 730-2014, IEEE 1012-2016.
