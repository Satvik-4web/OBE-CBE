# UNC801: Information Retrieval
**Semester**: Semester VIII | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PEC | **L-T-P**: 3-0-0 | **Credits**: 3.0 | **Contact Hours**: 3

## 🎯 Course Objective
To provide a comprehensive introduction to fundamental concepts, algorithms, and techniques in Information Retrieval (IR) including indexing, querying, ranking documents, vector space models, and ML for retrieval.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Comprehend fundamental concepts and terminology associated with Information retrieval.
- **CLO2**: Understand and evaluate various types of indices and efficient storage of indices.
- **CLO3**: Evaluate scoring strategies and ranking models.
- **CLO4**: Analyze and implement advanced indexing, link analysis, and duplicate detection techniques for scalable web search.
- **CLO5**: Utilize machine learning methods for intelligent information retrieval.

## 📚 Syllabus & Topics
- Introduction & Inverted Indexes: Boolean queries, bi-word indexes, positional indexes, tokenization.
- Index Construction: Blocked sort-based indexing, single-pass in-memory indexing, distributed indexing, index compression (Heap's law, Zipf's law, dictionary compression).
- Scoring & Ranking: Tf-idf weighting, vector space model, cosine similarity, champion lists, tiered indexes.
- Link Analysis & Web Search: PageRank, HITS, duplicate detection (shingling, min-hashing).
- Retrieval using ML: Word embeddings, learning to rank, classification-based retrieval.
- Standards Familiarization: IEEE 610.12-1990, IEEE 1061-1998, IEEE 1012-2016, IEEE 730-2014, IEEE 754-2019.
