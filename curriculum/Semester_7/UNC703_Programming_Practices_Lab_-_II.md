# UNC703: Programming Practices Lab - II
**Semester**: Semester VII | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: PCC | **L-T-P**: 0-0-2 | **Credits**: 1.0 | **Contact Hours**: 2

## 🎯 Course Objective
Advanced competitive programming, dynamic programming on trees, advanced graph theory, and real-time coding assessments.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Apply advanced programming techniques in Java/Python to complex algorithmic problems.
- **CLO2**: Implement tree and graph algorithms with optimal time and space complexity.
- **CLO3**: Formulate strategies for complex competitive programming and technical interviews.
- **CLO4**: Perform timed problem solving demonstrating code robustness and edge-case handling.

## 📚 Syllabus & Topics
- Advanced dynamic programming, bitmask DP, segment trees, fenwick trees, flow networks, heavy-light decomposition, placement mock interviews.

## 📖 Prescribed Text Books & References
1. Halim, Steven, Competitive Programming 4.
1. Kleinberg, Jon and Tardos, Eva, Algorithm Design, Pearson.
