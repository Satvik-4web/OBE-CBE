# UES103: Programming for Problem Solving
**Semester**: Semester II | **Program**: B.E. Electronics and Computer Engineering (ENC)
**Category**: ESC | **L-T-P**: 3-0-2 | **Credits**: 4.0 | **Contact Hours**: 5

## 🎯 Course Objective
This course is designed to solve and explore the problems using the art of computer programming with the help of C Language. Students will be able to apply these problem solving concepts in real life applications.

## 📋 Course Learning Objectives (CLO) / Course Outcomes (CO)
Upon successful completion of this course, the students will be able to:
- **CLO1**: Comprehend and analyze the concepts of number system, memory, compilation and debugging of the programs in C language.
- **CLO2**: Analyze the control & iterative statements to solve problems with C language source codes.
- **CLO3**: Design and create programs for problem solving involving arrays, strings and pointers.
- **CLO4**: Evaluate and analyze programming concepts based on user-defined data types and file handling using C language.

## 📚 Syllabus & Topics
- Introduction to Computer Fundamentals: Computer Memory Hierarchy, Types of Software, Binary number system, Algorithm, Flowchart, Simple algorithms for logical and arithmetic problems.
- Basics of C Programming: Structure and Life cycle of a C Program, Data types, Identifiers, Variables, Keywords, Constants, I/O statements, Operators, Type conversion and casting.
- Decision Making and Iterative Statements: if, if-else, Nested if-else, switch, Ternary Operator, Loops (while, do-while, for), Nesting of Loops, break, continue and goto.
- Functions & Recursion: Function prototype, Definition and Call, Scope of variables, Storage classes, Recursion, Tower of Hanoi.
- Arrays, Strings & Pointers: 1D and 2D arrays, Array operations, Strings, String functions. Pointers, Pointer arithmetic, Call by value and reference, Dynamic memory allocation (malloc, calloc, realloc, free).
- Structures, Union & File Handling: Structure declaration, accessing members, Array of structures, Structure pointers, Comparison with Union. File streams, file opening/closing, reading, writing, appending, command line arguments.
